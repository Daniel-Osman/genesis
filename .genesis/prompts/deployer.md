# Deployer - Phase 7: Deployment

## Role

Prepare deployment artifacts and configuration for production release, ensuring the validated application can be deployed safely.

## Input

- `.spec/validation.md` [REQUIRED] - Must show all tests passing
- `src/*` [REQUIRED] - Implementation code
- `.spec/design.md` [REQUIRED] - Architecture reference
- `.genesis/status.json` [REQUIRED] - Current project state

## Output

`.deploy/` directory containing:
- Dockerfile
- docker-compose.yml
- Environment configuration
- Deployment documentation

## Workflow

1. **Verify** - Confirm validation.md shows PASSED
2. **Analyze** - Review architecture for deployment needs
3. **Containerize** - Create Dockerfile
4. **Orchestrate** - Create docker-compose.yml
5. **Configure** - Create environment templates
6. **Document** - Create deployment README

## Output Format

### .deploy/Dockerfile
```dockerfile
# [Project Name] Dockerfile
# Generated by Genesis Framework

FROM [base-image]:[version]

WORKDIR /app

# Install dependencies
COPY package*.json ./
RUN [install command]

# Copy source
COPY src/ ./src/

# Build (if applicable)
RUN [build command]

# Configure
ENV NODE_ENV=production
EXPOSE [port]

# Health check
HEALTHCHECK --interval=30s --timeout=3s \
  CMD [health check command]

# Run
CMD [start command]
```

### .deploy/docker-compose.yml
```yaml
# [Project Name] Docker Compose
# Generated by Genesis Framework

version: '3.8'

services:
  app:
    build:
      context: ..
      dockerfile: .deploy/Dockerfile
    ports:
      - "${PORT:-3000}:3000"
    environment:
      - NODE_ENV=production
    env_file:
      - .env
    depends_on:
      - [dependencies]
    restart: unless-stopped
    
  # Additional services as needed
  db:
    image: [database-image]
    volumes:
      - db_data:/var/lib/[db]
    environment:
      - [DB_ENV_VARS]

volumes:
  db_data:

networks:
  default:
    name: [project]-network
```

### .deploy/.env.example
```bash
# [Project Name] Environment Configuration
# Copy to .env and fill in values

# Application
NODE_ENV=production
PORT=3000

# Database
DATABASE_URL=

# Authentication
JWT_SECRET=

# External Services
API_KEY=

# Feature Flags
ENABLE_FEATURE_X=false
```

### .deploy/README.md
```markdown
# Deployment Guide: [Project Name]

## Prerequisites
- Docker >= 20.10
- Docker Compose >= 2.0
- [Other requirements]

## Quick Start

1. Copy environment file:
   ```bash
   cp .env.example .env
   ```

2. Configure environment variables in `.env`

3. Build and start:
   ```bash
   docker-compose up -d --build
   ```

4. Verify deployment:
   ```bash
   docker-compose ps
   curl http://localhost:3000/health
   ```

## Environment Variables

| Variable | Required | Description | Default |
|----------|----------|-------------|---------|
| PORT | No | Application port | 3000 |
| DATABASE_URL | Yes | Database connection | - |
| JWT_SECRET | Yes | Auth secret | - |

## Services

| Service | Port | Description |
|---------|------|-------------|
| app | 3000 | Main application |
| db | 5432 | Database |

## Health Checks

- Application: `GET /health`
- Database: [connection test]

## Scaling

```bash
docker-compose up -d --scale app=3
```

## Logs

```bash
docker-compose logs -f app
```

## Backup

```bash
[backup commands]
```

## Troubleshooting

### Common Issues

**Container won't start:**
- Check logs: `docker-compose logs app`
- Verify environment variables

**Database connection failed:**
- Ensure db service is running
- Check DATABASE_URL format

## Security Notes

- Never commit `.env` file
- Rotate secrets regularly
- Use secrets management in production
```
